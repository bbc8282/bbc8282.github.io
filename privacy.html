개인정보처리방침

클로 (Klo) · 최종 수정일 2026년 10월 11일

1. 개요

클로("본 앱")는 제작자 본인만 사용하는 개인용 비서 애플리케이션입니다. 제작자가 소유·운영하는 사설 서버에서 동작하며, 제3자에게 배포하거나 서비스로 제공하지 않습니다. 본 방침은 본 앱이 Google 사용자 데이터를 어떻게 취급하는지 설명합니다.

2. 수집·접근하는 정보

본 앱은 사용자가 OAuth 동의를 통해 명시적으로 허용한 범위에 한해 다음 Google 데이터에 접근합니다.

  • Google 캘린더 — 일정 조회, 생성, 수정
  • Gmail — 메일 조회 및 요약
  • Google Drive / Docs / Sheets — 문서 조회 및 편집
  • 연락처 — 일정 참석자 지정
  • 계정 이메일 주소 — 계정 식별 용도

본 앱은 광고 식별자, 위치 정보, 결제 정보를 수집하지 않습니다.

3. 이용 목적

수집된 데이터는 오로지 사용자 본인에게 비서 기능(일정 관리, 알림, 메일 요약 등)을 제공하기 위해서만 사용됩니다. 다른 목적으로 사용하지 않습니다.

4. 저장 및 보안

  • 데이터와 인증 토큰은 제작자가 소유한 사설 서버에만 저장됩니다.
  • 인증 토큰은 파일 권한 600으로 보호되며 암호화된 키링에 보관됩니다.
  • 서버는 사설 네트워크(Tailscale)로만 접근 가능하며 공개 인터넷에 노출되지 않습니다.
  • 외부 데이터베이스나 클라우드 저장소로 전송하지 않습니다.

5. 제3자 제공

본 앱은 Google 사용자 데이터를 어떠한 제3자에게도 판매·양도·공유하지 않습니다. 광고에 사용하지 않으며, 인적 열람(human review)을 하지 않습니다.

6. Google API 서비스 사용자 데이터 정책

본 앱이 Google API로부터 받은 정보의 사용 및 전송은 Google API Services User Data Policy를 준수하며, 여기에는 제한적 사용(Limited Use) 요건이 포함됩니다.

Klo's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. 데이터 보관 및 삭제

데이터는 기능 제공에 필요한 기간 동안만 보관되며, 사용자가 접근 권한을 철회하면 저장된 토큰과 캐시는 삭제됩니다. 사용자는 아래 경로에서 언제든 권한을 철회할 수 있습니다.

https://myaccount.google.com/permissions

본 방침이 변경되면 이 페이지에 갱신된 내용과 수정일을 게시합니다.
